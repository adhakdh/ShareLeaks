# ShareLeaks

The files in this repository are provided for the paper **ShareLeaks**.

This repository contains the main datasets, experimental scripts, and source code required to reproduce the core evaluation results reported in the paper.

## Repository Structure

```text
├── Datasets/
├── ExperimentalResults/
│   ├── shareleaks_results/
│   ├── run.py
│   ├── s1_ExtractVideoFrames.py
│   ├── s2_DetectRayKeyboard.py
│   ├── s3_MapKeyboardKeys.py
│   ├── s4_ExtractKeyEvents.py
│   ├── s5_rebuilt.py
│   ├── s6_SavedResults.py
│   ├── s7_PrintResults.py
│   └── shareleaks_lib.pyc
├── SourceCode/
└── README.md
```

We organize the repository into three main components:

1. **Datasets**: Contains the datasets used in the main experiments reported in the paper.

2. **ExperimentalResults**: Contains the experimental scripts, supporting libraries, and intermediate results required to reproduce the main quantitative evaluations.

3. **SourceCode**: Contains the source code for the ShareLeaks processing pipeline.

## 2. Datasets

The `Datasets` directory contains the main datasets used in our evaluation.

These datasets consist of XR first-person-view (FPV) recordings collected for evaluating the ShareLeaks inference pipeline. They provide the input data used to assess the reconstruction of sensitive input interactions from shared XR recordings.

## 3. Reproducing the Experimental Results

All scripts and intermediate results required to reproduce the main experimental results are located in:

```text
ExperimentalResults/
```

The experimental pipeline consists of seven sequential processing stages, implemented in `s1_ExtractVideoFrames.py` through `s7_PrintResults.py`.

The `run.py` script serves as the main entry point and coordinates the execution of these stages.

### 3.1 Main Experimental Pipeline

To reproduce the main experimental results, enter the `ExperimentalResults` directory and execute:

```bash
cd ExperimentalResults
python run.py
```

The script executes the ShareLeaks processing pipeline and generates the corresponding inference results.

### 3.2 Processing Stages

The ShareLeaks pipeline consists of the following seven stages:

| Script | Processing Stage |
|---|---|
| `s1_ExtractVideoFrames.py` | Extract video frames and associated metadata |
| `s2_DetectRayKeyboard.py` | Detect interaction rays and keyboard regions |
| `s3_MapKeyboardKeys.py` | Map detected keyboard regions to individual keys |
| `s4_ExtractKeyEvents.py` | Extract key interaction events |
| `s5_rebuilt.py` | Refine and filter key candidates |
| `s6_SavedResults.py` | Save processed inference results |
| `s7_PrintResults.py` | Calculate and report evaluation results |

These stages collectively implement the ShareLeaks inference workflow, from processing input FPV recordings to generating the final evaluation results.

### 3.3 Intermediate Results and Experimental Outputs

The `shareleaks_results` directory contains the intermediate results and experimental outputs generated by the processing pipeline.


The repository includes key intermediate results required for reproducing the main experiments. These resources support the execution of the pipeline and the generation of the reported evaluation results.

## 5. Repository Scope

Due to repository storage limitations, this artifact currently includes the **main datasets, experimental scripts, and key intermediate results necessary to reproduce the core results of the paper**, rather than the complete collection of data generated throughout the study.

The included intermediate results enable the main experimental pipeline to be executed using `run.py`, producing the corresponding evaluation results.
